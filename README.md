# Avila Infrastructure & Contracting — Landing Page

Marketing landing page for **Avila Infrastructure & Contracting**, an owner-operated utility
contracting business serving California's Central Valley (based in Lemoore, CA).

## Stack

Single-file static site — no build step, no dependencies.

- `index.html` — the entire page (HTML, CSS, and JS inline)
- `assets/` — logo, favicon, and icon images

## Design

"Business card" concept: red (`#C10D17`), ink black, and paper white, with angled dividers,
a blueprint-grid motif, and Bebas Neue / Inter / Share Tech Mono typography.

## Sections

Hero · Services · Why Avila · Service Area · Contact (with estimate request form) · Footer

## Local preview

Any static file server works, e.g.:

```bash
npx serve -l 3456 .
```

Then open http://localhost:3456
